## 首页版式

**已付费 / 未付费已约**

头部装饰（200px）→ Banner（343×149）→ 学习数据（343×168）→ 下一次课（标题 + 343×242 渐变卡）→ 学习资源（胶囊 Tab + 2×2 卡片）→ 课程中心（最近学习 / 主修课 / 专项课 / AI课 + 219/118 课程卡）→ 到底啦~

**游客 / 未付费未约**

头部装饰 → Banner → 学习资源 → 三入口（学习资料 / 了解我们 / 课程顾问）→ 免费试听课 CTA；底部仅保留「首页 + 我的」。

## 关键还原点

- 手机画布 375×812，16px 左右边距；底部 Tab 48 + 34 安全区，含 Home Indicator。
- 头部三张矢量装饰、品牌 Logo、学员胶囊均来自设计稿。
- Banner 按 V1 使用单张 343×149「周周分享得赠课」，不再使用旧版三图轮播（旧图 343×130 且带旧分页点）。未付费试听转化位独立放在游客页下方。
- 学习数据：343×168 渐变卡 + 209×96 数据面板 + 98×96 等级环。
- 下一次课：343×242，绿色渐变顶栏 + 白色内容面板，含日期/时间、状态、课程信息、老师、学习任务与圆形入口。
- 课程中心：4 个 Tab、219px「学习中」卡、118px「未约课」卡，进度/距下一级别/上次学习均保留。
- 资源卡、游客三入口、试听 CTA 使用设计稿导出整图，文案与插画一致。
- 从 `67:1208` 补充：活动福利三卡（分享赚课时 + 任务中心 + 专属海报）；多孩模式下学习数据标题独立、卡片内显示学员名，下一次课显示学员头像，课程卡增加学员胶囊并切换为 251px 学习卡。
